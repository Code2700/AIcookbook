# 🍳 AI Cookbook

A hands-free, camera-aware cookbook. Browse recipes, cook with voice guidance, and scan your fridge to see what you can make.

## Status

**M0 — Foundation** ✅

## Planned Features

- 🍽️ Browse and search recipes
- 🎤 Hands-free cooking mode (voice navigation + read-aloud)
- 📷 Camera mode — scan ingredients, get recipe suggestions
- 📱 Installable PWA, works offline
- 🌙 Dark mode + kitchen-friendly large-font UI
- 🛒 Grocery lists, recipe scaling, AI chat chef

## Tech Stack

Plain **HTML, CSS, JavaScript**. No frameworks. Recipes via [TheMealDB](https://www.themealdb.com/).

## Development

Open this folder in VSCodium, install the recommended extensions when prompted, then right-click `index.html` → **"Open with Live Server"**. Site runs at `http://127.0.0.1:5500`.

**Important:** Camera and microphone APIs require `http://localhost` or `https://` — they will not work on `file://`. Always use Live Server during development.
